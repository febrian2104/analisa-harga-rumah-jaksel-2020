# Analisis Harga Rumah di Jakarta Selatan Tahun 2020

Proyek ini menganalisis harga rumah di Jakarta Selatan pada tahun 2020 menggunakan data yang diperoleh dari Kaggle.

Sumber data: [Daftar Harga Rumah di Kaggle](https://www.kaggle.com/datasets/wisnuanggara/daftar-harga-rumah)

- Hasil analisis deskriptif dapat dilihat dalam [laporan analisis deskriptif](reports/deskriptif/analisis_deskriptif.md).
- Hasil pemodelan dapat dilihat dalam [laporan pemodelan](reports/pemodelan/laporan_pemodelan.md).
- Hasil validasi model dapat dilihat dalam [laporan validasi model](reports/validasi_model/laporan_validasi_model.md).
